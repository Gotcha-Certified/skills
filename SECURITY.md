# Skill safety

Skills are instructions that an agent may choose to follow. Review them with the same care you would give a reusable prompt or automation.

The most common problem is not hidden malware. It is a poorly written instruction that gives the agent the wrong goal, asks for too much access or produces weak work.

Before installing an unfamiliar skill:

- Read `SKILL.md`.
- Check any supporting files.
- Ask your agent to explain what the skill will make it do.
- Check which sources, tools and permissions the skill expects.
- Do not share information that you or your organisation are not allowed to use.

If you find a security problem in a Gotcha skill, use GitHub's private vulnerability reporting for this repository. Do not publish sensitive details in a public issue.
